# 易用性 4/4：完整网页旅程、部署文档与最终验收证据

## 目标与前置

前置：订单 60、61、62 均已验收。按用户 2026-10-28 最新决定，交付可供私人试运行的完整版本：每台电脑一次性安装并配置私有 CA 信任，日常使用中转地址和个人令牌；先使用已经接通的真实 API 上游。

本任务书按 [私人使用决定](../PRIVATE-USE-PLAN.md) 更新，取代本单原任务书及旧批示中要求“当前必须取得公网可信证书、必须完成真实官方账户调用才可验收”的条款。官方账户待用户实际运行一段时间、确认好用稳定后再接；公网域名和对外部署在程序可用后按需安排。这两项不阻止本单私人版本验收，未实测仍须如实标明。

## 必须实施与验证

1. 在干净服务端数据目录及目标客户端运行完整旅程：启动、网页首次设置、管理身份、私有 CA HTTPS、真实 API 上游配置测试、创建两位使用者、一次性证书信任、复制连接说明、调用、用量查询、轮换/停用、重启。日常管理通过网页完成。
2. 将私有 CA 作为当前私人部署方案提供清晰的安装、信任与检查步骤，按实际客户端验证；若 Claude Code 需要客户端专用 CA 配置，应由一次性引导落实并记录，不能把系统或浏览器信任等同于所有客户端均信任。安装完成后，普通使用者日常只需地址与个人令牌。连接页面不得继续把用户选定的私有 CA 方案一概显示成不合格的旧路线。
3. 复用现有两家真实 API 上游，验证网页接入、JSON/SSE、工具、模型选择、用量、切换及重启。保留账户/API 两种模式的模拟协议、权限、失效恢复和用量回归；当前不进行官方账户登录或真实调用，不读取官方账户凭据。
4. 验证私有 CA 的真实 TLS 连接、名称匹配、有效期、未信任与错误证书失败、流事件及时刷新。公共证书可分发到客户端，CA 私钥及服务端私钥不进入客户端包。保留正常证书校验，禁止通过关闭校验使测试通过。
5. 复查两人归属、并发、取消、错误语义、未知及部分用量、新旧数据迁移、正常重启、异常退出恢复、滚动 40 天清理和停机跨期启动。升级/回退说明覆盖数据格式和 DPAPI 身份绑定。
6. 浏览器验证无秘密回显、越权、CSRF、首次设置抢占；检查键盘操作、标签、加载/失败/空状态、令牌一次性展示、复制提示及小屏布局。用虚构秘密标记检查普通响应、SSE、响应头和日志。
7. 更新 README 和验证记录，提供中文私人部署、每台电脑证书信任、网页日常操作、客户端配置、备份恢复与故障定位。说明程序所在主机、可达地址、域名及映射的关系；公网可信证书作为以后可选的部署方式介绍，不要求现在购买域名或上线公网。
8. 提供发布包、完整构建及测试输出、浏览器记录、脱敏真实 API 调用结果、提交标识及试运行观察方法。记录启动、重启、错误、资源占用和用量正确性的观察途径，不保存提示词、回答或凭据。试运行期限与是否接入官方账户由用户根据实际使用决定。

网页配置到可用个人凭据；真实 API 经私有 CA HTTPS 完成 JSON/SSE 和工具调用；一次性客户端信任过程可复现；两人用量归属与停用正确；重启持久化和 40 天清理正确；页面及报错不泄露上游秘密。未知用量明确展示，不能写零冒充完整结果。
