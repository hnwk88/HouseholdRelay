# 站点设备维护

站点设备编号在全新站点建立时生成一次。重启、升级、重新登录、增加或删除账户、导入账户都沿用本站编号。每台电脑的个人中转令牌用于授权和用量归属，与站点设备编号分开。

管理员可在本机管理页面打开“设备维护”。页面不显示原始编号，也不允许填写任意编号。更换需要确认暂停范围：本站全部官方账户暂时停止接受新操作，等待已有调用、流式响应和登录程序结束，最多六十秒。等待超时会提示未更换，原操作继续；独立 API 上游仍可使用。

提交新编号后，本站逐一准备私有账户配置。准备最多等待三十秒，失败会显示“更换未完成”，保持官方账户暂停。修复本站私有配置后按“继续原操作”；重启也会继续同一个目标，不再生成另一个编号。重复提交同一操作不会重复更换，过期页面不能覆盖较新的维护。

设备维护不会解除上游认证暂停、限流或账户限制，不会自动重新登录、测试账户或切换候选。它也不会重发个人令牌、合并会话或改变客户端地址、证书信任及个人用量归属。更换设备编号不能保证解除账户限制。

## 升级、备份和恢复

升级前停止本实例，确认其管理的 Claude 子进程已退出，并备份完整数据目录及配套 Windows 虚拟机。必须保留 `.relay-instance` 与 `.state` 数据库、私有账户目录、证书及 DPAPI 所依赖的 Windows 用户环境。仅复制一个账户的登录文件不构成完整站点备份；完整搬家按现有虚拟机迁移说明处理，旧副本不能同时转发或续期。

此版本把数据库升级到版本 8，保留既有合法编号。数据库配置缺少或损坏编号时明确拒绝启动，不会重新开放首次设置或补造编号。工程私有账户配置在取得服务排他锁之后准备，只修改 `userID`，保留其他配置和登录凭据；个人 Claude 或 MyCoAI 目录不在准备范围内。配置损坏、目录链接或未知冲突会停止官方准备，需恢复可信的本站配套备份后再继续。

升级失败时先停止新版本，再恢复升级前的完整配套数据目录和旧程序。旧程序不支持版本 8；不能仅覆盖程序、降低数据库版本号，或混用新旧文件来回退。新编号已经提交的情况下，应优先使用本版本继续原操作；不要让两个配套备份同时运行。

本站还会在启动自有 Claude 子进程前记录一次最小的进程状态。服务意外退出后，若原子进程仍存活，官方准备继续暂停；确认原进程退出后可再次继续。若故障恰好发生在启动与取得进程编号之间，程序无法自动证明旧进程不存在，会保持暂停，不会猜测清除。此时“继续原操作”不保证单击恢复：先停止本站服务及其旧 Claude 进程，由维护人员核实后处理；无法核实则停止承载虚拟机并按上述完整配套备份流程恢复。不要批量结束个人 Claude，也不要猜着删除进程记录或凭据文件。

## 协议和临时取证

官方 Messages 路径目前支持旧式 `user_…_account_…_session_…` 和内嵌 JSON `device_id` 两种身份格式，只替换设备值。无法识别、缺字段、重复相关键或损坏格式会在本站拒绝，不进入官方认证暂停或限流。该限制是本站支持范围；公开 Messages API 的 `metadata.user_id` 本身是可选项。

模型目录没有正文，不添加设备字段。计数端点不添加 metadata，目前本站官方路径拒绝携带该扩展；独立 API 按原始正文转发。兼容账户上游仍遵循项目设置中的归一化开关，官方路径始终执行统一规则。

需要排查时，可在设备维护页开启“临时脱敏取证”。最多十分钟或一百条样本，任一到达即停止，重启后默认关闭。记录区分组装、交给发送器、收到响应以及本地拒绝；已交发送不代表官方一定收到。CLI 记录仅代表实际观测到的进程结果。未观测的环境、目录、会话和官方网络字段明确标为未知。

取证不会主动发请求，不记录原始凭据、Cookie、账户号、设备值或完整对话。错误类型和请求编号仍可在既有用量尝试记录中查看；403 不能单凭状态码认定为令牌失效或永久封号。站点身份与 OAuth 授权历史是两件事，更换编号不清除账户或授权关联。
